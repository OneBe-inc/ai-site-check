# OneBe AIっぽさ診断

提供されたデザイン画像をもとにしたレスポンシブなランディングページです。

公開URL: https://onebe-inc.github.io/ai-site-check/

## 実装

- ビルド不要の HTML / CSS / JavaScript。`main` ブランチのルートを GitHub Pages で配信。
- FV はヘッダー込みで `100svh`。URL入力と送信ボタンまで初期画面内に配置。
- OneBe のブランドライブラリから取得した実際の SVG ロゴをヘッダー・フッターに使用。
- 提供画像を参照して人物・制作イメージ5点を画像生成で高解像度のラスター原画に再制作。透過WebPとsrcset/sizesで配信。主要テキスト、URLフォーム、FAQ、ナビゲーションはHTMLで実装。
- FAQの開閉、全件開閉、モバイルメニュー、説明ダイアログ、URL形式の検証に対応。
- 入力URLをサーバーへ送信・保存しない。アクセス解析タグなし。
- デザインプレビューとして `noindex,nofollow` を設定。

## 診断機能

診断APIは未接続です。URLを入力すると `report.html` のレポート画面へ進みます。入力URLはURLフラグメントで画面内だけに引き継ぎ、HTTPリクエストや永続ストレージには含めません。

レポートは、追加提供された診断レポート画像に基づくVAIZOの画面設計用サンプルです。35/100 の2つのスコアと改善コメントは画像内の例であり、入力したサイトを解析して得た結果ではありません。画面の上部・下部と入力URLの案内でサンプルであることを表示します。

実解析機能は含まれていません。トップページのイラスト内の「32」も提供画像に含まれる表示例です。

## 素材

- OneBe SVG ロゴ: OneBeの自社ブランド素材。独自に描き直していません。
- イラスト・制作イメージ: ユーザー提供の構図を参照し、内蔵ImageGenで再制作したラスター画像。ベクターイラスト・ベクターからのラスター化は使用していません。顔・ポーズ・服装を揃えて5点を制作。生成に伴う細部の変化があります。
- 原画: ヒーロー1362×1155、思案する人物1300×1210、制作イメージ1566×1004、レポート人物1426×1103、相談人物1511×1041。単純なアップスケールではありません。
- レポートのサイト画像: 記載のVAIZO公開サイトを2026-10-27にブラウザで撮影。400/800/1200px幅のWebPで配信。
- UIの小さなアイコン・スコア円と正式ロゴは既存のSVGを維持。人物・制作イメージをSVGやCSSで描画していません。旧SVG切り抜きマスクは削除。
- 再制作したデバイス画像は制作イメージであり、実在する納品実績やスタッフ写真ではありません。
- Noto Sans JP: Google Fonts から取得した可変WOFF2。使用文字のサブセット。ライセンスは `assets/OFL.txt`。
- SNSアカウントの未確認リンクは作成せず、フッターには確認済みのメール窓口を配置。
